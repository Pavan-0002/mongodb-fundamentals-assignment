# MongoDB Fundamentals Assignment

## Library Management System

This repository contains my MongoDB Fundamentals assignment for EdQuest.

### Contents

- `MongoDB_Assignment.md` — Complete written assignment
- `mongodb_library_queries.js` — MongoDB database, CRUD, search, update, delete, sorting, projection, counting and indexing queries

### Topics Covered

- Introduction to MongoDB
- NoSQL concepts
- MongoDB data model
- Installation and configuration
- Library Management System case study
- CRUD operations
- Searching books by title, author, genre, and year
- Filtering and multiple conditions
- Projection and sorting
- Updating and deleting documents
- Indexing
- Advantages and limitations of MongoDB
- Importance of NoSQL in modern applications

## How to Run

1. Install MongoDB Community Server and MongoDB Shell.
2. Open MongoDB Shell.
3. Open `mongodb_library_queries.js`.
4. Execute the commands in MongoDB Shell.
5. Verify the inserted documents and query results.
